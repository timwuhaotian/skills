# 十二宫释义与看盘要点

> 用途: 排盘后撰写解读时查阅。十二宫沿命宫起逆时针排布: 命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友(仆役)、官禄(事业)、田宅、福德、父母。看任何一宫都不能只看本宫, 须兼顾三方四正(本宫、对宫、两个三合宫)。

## 一、十二宫逐一说明

### 命宫
- 含义: 一生的总格局、性格底色、天赋取向与人生主轴, 全盘第一优先。
- 掌管: 性格、气质、才能倾向、行事风格、先天格局高低。
- 看盘要点: 先看主星组合与亮度定基调; 再看三方四正(命、财帛、官禄、迁移)会入哪些吉星煞星; 命宫无主星时借对宫迁移宫主星参看。身宫与命宫同看, 命主先天, 身主后天走向。

### 兄弟宫
- 含义: 兄弟姐妹的缘分、助力与相处模式。
- 掌管: 手足关系、平辈(朋友、同事、合伙人)互动、母亲位(部分派别取用)、母亲与家庭内部支持。
- 看盘要点: 主星吉凶看手足感情厚薄与合作是否顺遂; 此宫也常用于观察合伙创业的适配度。煞星多不代表无兄弟, 只提示相处需磨合。

### 夫妻宫
- 含义: 婚恋关系的形态、配偶的特质倾向、两人的相处模式。
- 掌管: 感情、婚姻、配偶形象、亲密关系的课题。
- 看盘要点: 看主星性质推测相处模式(如七杀主快速直接, 天同主温和随缘); 太阳、太阴分别是传统上丈夫、妻子的参考星; 对宫官禄、三合福德与迁移需合参。煞星或化忌多只说明"需要更多磨合与经营", 严禁据此断言离婚或配偶不佳。

### 子女宫
- 含义: 子女缘分、亲子关系与生育相关课题。
- 掌管: 子女多寡与缘分厚薄、亲子互动、学生与晚辈、创作作品("作品如子女")、性生活(传统取用)。
- 看盘要点: 以缘分深浅、相处之道描述为主; 涉及生育、子女成就等话题务必温和、留有余地, 并注明仅供参考。

### 财帛宫
- 含义: 赚钱方式、理财能力与现金流动状况。
- 掌管: 收入形态(薪资/业务/投资)、金钱观、现金流起伏。
- 看盘要点: 主星性质决定"怎么赚"(武曲务实赚、贪狼应酬赚、天机靠脑力、破军敢博等); 化禄、化权入财帛主财源活络; 财帛需与命宫(赚钱魄力)、官禄(事业生财)、田宅(存得住否)合参。

### 疾厄宫
- 含义: 体质倾向与身心薄弱环节。
- 掌管: 先天体质、易出现的系统失衡、情绪与压力的躯体化表现。
- 看盘要点: 只谈"哪个系统需留意", 不下诊断、不断病、不吓人; 主星五行与煞星提示倾向(详见 interpretation-guide.md 的健康维度规范); 疾厄亦需与福德(情绪)同看。

### 迁移宫
- 含义: 离家在外的发展、社交舞台与外部世界。
- 掌管: 异地发展、出行差旅、在外人缘、环境变动、外出际遇。
- 看盘要点: 迁移是命宫对宫, 直接影响命局——命宫弱而迁移强, 传统认为离乡背井、外出发展更顺; 煞星聚迁移提示在外需谨慎择友、注意交通安全与文书。

### 交友宫(仆役宫)
- 含义: 朋友圈层、部属素质与群众基础。
- 掌管: 朋友助力或拖累、下属与同事、客户与粉丝(现代引申)。
- 看盘要点: 吉星会聚主得力伙伴与优质人脉; 煞忌多提示识人需谨慎、慎担保慎借贷; 领导者尤重此宫。

### 官禄宫(事业宫)
- 含义: 职业性质、事业成就与工作态度。
- 掌管: 适合的行业与岗位类型、事业发展轨迹、职场表现、社会成就。
- 看盘要点: 主星结构定事业类型——机月同梁偏文职企划, 杀破狼偏开创变动, 阳梁昌禄偏文教公职, 紫府相偏管理佐贰; 与命宫、财帛互为三方, 三者合看定事业总貌; 化忌入官禄提示工作压力是人生功课所在。

### 田宅宫
- 含义: 不动产、家庭环境与"库位"。
- 掌管: 置产能力、祖业家运、居住环境、办公室与据点、财库(钱财能否积存)。
- 看盘要点: 太阴为田宅主, 庙旺利置产; 田宅也代表幕后环境与安全感来源; 煞忌聚则置产过程多波折或搬迁频繁, 描述时留余地。

### 福德宫
- 含义: 精神生活、兴趣爱好、福气与心态。
- 掌管: 内心世界、情绪习惯、兴趣品味、晚年安排, 也是财的"气数位"(影响财源能否长流)。
- 看盘要点: 福德好则心态稳、懂得享受; 煞忌聚则思虑多、自寻烦恼, 建议给出情绪管理方向; 福德与夫妻对望, 内心状态会投射到亲密关系。

### 父母宫
- 含义: 与父母的缘分、长辈关系与庇荫。
- 掌管: 父母形象与缘分、父母健康倾向(仅供提醒)、上司长辈缘、公家文书与学历证明(传统取用)。
- 看盘要点: 看与长辈上司的互动模式; 太阳(父)、太阴(母)的亮度作辅助参考; 化忌入父母提示与父母沟通或文书事务需多用心。

## 二、三方四正速查

| 宫位 | 三方四正(本宫 + 三合两宫 + 对宫) |
|---|---|
| 命宫 | 命、财帛、官禄、迁移 |
| 兄弟宫 | 兄弟、疾厄、田宅、交友 |
| 夫妻宫 | 夫妻、迁移、福德、官禄 |
| 子女宫 | 子女、交友、父母、田宅 |
| 财帛宫 | 财帛、官禄、命宫、福德 |
| 疾厄宫 | 疾厄、田宅、兄弟、父母 |
| 迁移宫 | 迁移、福德、夫妻、命宫 |
| 交友宫 | 交友、父母、子女、兄弟 |
| 官禄宫 | 官禄、命宫、财帛、夫妻 |
| 田宅宫 | 田宅、兄弟、疾厄、子女 |
| 福德宫 | 福德、夫妻、迁移、财帛 |
| 父母宫 | 父母、子女、交友、疾厄 |

> 推算规则: 从本宫起数, 顺时针每隔四位为三合宫, 对面第六宫为对宫。自行推算时可按此校验。

常用组合:
- 论性格格局: 命 + 财 + 官 + 迁(所谓"三方四正"狭义即此)。
- 论感情: 夫妻 + 福德 + 官禄 + 迁移。
- 论财富: 财帛 + 田宅(库)+ 福德(源)。

## 三、使用提醒
1. 宫位吉凶是"领域+倾向", 不是判决书; 同一宫煞星多也可解读为"该领域磨练多、成长快"。
2. 六亲宫(父母、兄弟、子女、夫妻)的描述必须注明仅供参考, 语气留三分余地。
3. 宫位之间互为表里: 福德差会拖累夫妻, 迁移旺会补强命宫, 解读时多讲联动, 少孤立断语。

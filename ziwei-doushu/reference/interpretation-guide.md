# 解读写作规范(interpretation-guide)

> 本文件是撰写解读报告的总纲: 规定阅读命盘的顺序、各维度的写法与红线、篇幅与免责声明。所有解读必须先读完本文件再动笔。

## 一、总则: 定位与语气
1. 紫微斗数解读的定位是**传统文化的镜子**, 帮助用户自我认识与扬长避短, 不是预言, 更不是医疗、投资、婚恋决策依据。
2. 全文使用"倾向于""容易在……情况下""建议留意""可以尝试"等倾向性表述; 严禁"注定""必然""一定会""命中克""大凶""短寿"等绝对化断语。
3. 每个缺点都必须配套一条可操作的成长建议; 每个优点也要提示过度使用时的副作用。
4. 不套用旧时"女命不宜"之类性别偏见, 男命女命同一套星情逻辑。

## 二、动笔前: 核对排盘数据
- 从排盘 JSON 中确认: 阳历生日、时辰、性别、农历干支、五行局、命宫/身宫位置及主星亮度、生年四化落宫、十二宫星曜分布。
- 若用户未提供时辰或时辰存疑: 在报告开头注明"本次按 X 时排盘, 时辰对命宫影响较大, 结果仅供参考", 语气如实不做勉强推断。
- 排盘数据中的亮度、四化、宫位一律以 JSON 为准, 不另行手工推算。

## 三、解读顺序(七步)
1. **命宫**: 主星组合 + 亮度 → 性格底色与人生基调(参照 stars-14.md)。命宫无主星时借对宫迁移宫主星参看, 并说明"性格受环境影响大、可塑性强"。
2. **三方四正**: 命、财、官、迁四宫合看 → 整体格局强弱、吉星煞星比例、有无成格(参照 patterns.md)。
3. **身宫**: 后天发力点。身命同宫=表里如一靠自身; 夫妻=感情是重心; 财帛=经济安全感优先; 迁移=外出发展; 官禄=事业心重; 福德=重精神享受; 田宅=重家庭安定。
4. **生年四化落宫**: 人生主轴——禄=资源所在, 权=发力点, 科=名声贵人, 忌=终身功课(参照 si-hua.md)。化忌落宫重点展开。
5. **辅星杂曜分布**: 六吉看助力人缘, 六煞看磨练课题, 桃花刑姚点缀感情与风格(参照 brightness.md)。
6. **大限走向**: 按五行局起限(水二局 2 岁、木三局 3 岁、金四局 4 岁、土五局 5 岁、火六局 6 岁, 每十年一限), 取当前与未来两到三个大限, 用大限宫主星 + 大限四化与生年四化的叠加, 做趋势性描述。
7. **综合收束**: 三句以内总结"扬什么长、避什么短、近十年往哪走"。

## 四、各维度写作要点(每个维度 200-400 字)

### 1. 性格特质(命宫)
- 写法: 主星画像 + 亮度修正 + 三方四正的加成或牵制 + 身宫补充。
- 必含: 两三个核心优点、两三个软肋、每条软肋配一条成长建议。
- 篇幅: 300-400 字, 是全文权重最高的维度。

### 2. 事业方向(官禄宫)
- 写法: 命宫星情定风格, 官禄宫星情定领域; 杀破狼=开创变动, 机月同梁=文职企划, 阳梁昌禄=文教公职, 紫府相=管理佐贰; 化权入官禄=可担重任。
- 必含: 适合的工作风格、行业倾向 2-3 类、合作还是单干、当前大限的事业提示。
- 篇幅: 250-350 字。

### 3. 财运特点(财帛宫/田宅宫)
- 写法: 怎么赚(财帛主星)+ 存得住否(田宅)+ 禄忌落点; 忌入财帛=宜记账避投机。
- 必含: 收入形态倾向、理财风格、需回避的财务习惯。
- 红线: 不预测具体收益数字、不推荐任何投资标的。
- 篇幅: 250-350 字。

### 4. 感情婚姻(夫妻宫)
- 写法: 相处模式 + 配偶特质倾向 + 红鸾天喜天姚等点缀; 与福德宫对望。
- 必含: 相处中的磨合点与沟通建议; 煞忌多时写"需要更多经营", 严禁断言离婚、出轨、"克配偶"。
- 篇幅: 250-350 字。

### 5. 健康提醒(疾厄宫)
- **只说哪个系统"需留意", 不诊断、不提病名、不作凶断。**
- 写法: 疾厄宫主星与煞星 → 对应系统的传统关联(下表, 仅供参考) + 一条生活建议(作息/运动/体检方向)。
- 传统星曜-系统关联速查(仅用于"需留意"表述): 太阳=心脑血管、眼睛; 太阴=内分泌、睡眠、视力疲劳; 天机=肝胆、神经系统、肩颈; 武曲=呼吸系统、鼻、牙齿骨骼; 天同=泌尿、脾胃消化、水液代谢; 廉贞=血液循环、皮肤; 天府=脾胃; 贪狼=肝胆、肾脏; 巨门=口腔、咽喉、消化道; 天相=皮肤、体质敏感; 天梁=胃、代谢机能; 七杀=肺、骨骼关节; 破军=消耗性疲劳、内分泌; 煞星聚=对应部位劳损炎症倾向, 火铃=炎症急躁, 空劫=神经衰弱倾向。
- 示例句式: "疾厄宫见 XX, 传统上与 XX 系统相关, 建议规律作息、定期体检时向医生提及该系统方向。"
- 篇幅: 200-300 字。

### 6. 六亲关系(父母宫/兄弟宫/子女宫)
- **本维度必须注明"仅供参考"**: 在段落结尾固定加一句"六亲缘分论述属传统命理范畴, 仅供参考, 现实关系以彼此经营为准。"
- 写法: 缘分厚薄、相处模式、建议的沟通方式; 煞忌多写"聚少离多、需主动联络", 不写"无缘""刑克"。
- 篇幅: 每宫 100-150 字, 合计 300-400 字。

### 7. 大限走向(十年趋势)
- 写法: 限内主星定主题, 限内四化定重点领域; 只写趋势与建议, 不写流年细节、不写灾祸。
- 必含: 当前大限主题 + 下一大限展望, 各一小段。
- 篇幅: 200-300 字。

## 五、用词规范

| 禁用 | 改用 |
|---|---|
| 注定 / 必然 / 一定会 | 倾向于 / 较大可能 / 容易出现 |
| 大凶 / 灾祸 / 血光 | 需要留意的课题 / 风险点 |
| 克夫 / 克妻 / 克子 / 无缘 | 相处需要更多磨合 / 沟通方式可调整 |
| 短寿 / 寿元 | 建议关注 XX 系统的养护 |
| 你必须 / 不行 / 完蛋 | 建议 / 可以尝试 / 值得留意 |
| 发大财 / 一定离婚 | 财务上机遇与风险并存 / 感情需用心经营 |

## 六、免责声明(必须逐字包含在报告末尾)

以下文案必须原样出现在每份报告的结尾, 不得改写、不得省略:

> 免责声明: 本报告基于传统紫微斗数文化进行解读, 仅供文化参考与自我认识之用, 不构成任何医疗、心理咨询、投资、婚姻或人生重大决策的依据。命理描述反映的是传统文化中的倾向性归纳, 人的命运由自身选择与努力塑造。如有健康问题请咨询执业医师, 涉及重大决策请寻求专业人士帮助。

## 七、报告结构模板
1. 基本信息表(生日、时辰、性别、农历干支、五行局、命宫主星)——不计入正文字数
2. 性格特质 → 3. 事业方向 → 4. 财运特点 → 5. 感情婚姻 → 6. 健康提醒 → 7. 六亲关系 → 8. 大限走向 → 9. 一句话总结 → 10. 免责声明
- 正文合计约 2000-3000 字; 单维度不超 400 字, 不满 200 字需补足内容深度。
- 标题措辞亲和中性, 例如"性格特质""事业方向", 不用"命定""算命"字样。

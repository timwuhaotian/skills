# 星曜亮度与辅星杂曜速查

> 用途: 排盘后撰写解读时查阅。亮度决定星曜"发挥几成功力"; 辅星杂曜决定格局的加分成色。解读口吻始终是"倾向"与"提醒", 不作吉凶判决。

## 一、亮度七档

排盘引擎对十四主星及部分辅星按所在宫位给出七档亮度(部分杂曜不标亮度, 属正常):

| 档位 | 力量 | 含义 | 解读要点 |
|---|---|---|---|
| 庙 | 最强 | 星曜处于最得力的位置 | 正面特质充分发挥, 吉星更吉; 煞星庙旺时破坏力也可控, 常转为冲劲与执行力 |
| 旺 | 很强 | 仅次于庙 | 特质鲜明、稳定发挥 |
| 得(得地) | 中上 | 力量足够 | 正常发挥, 平顺可用 |
| 利(利益) | 中等 | 吉凶互见 | 特质打折扣, 需吉星帮扶、煞星少扰 |
| 平(平和) | 中偏弱 | 特质不显 | 表现平平, 受三方四正影响更大 |
| 不(不得地) | 弱 | 优点难显 | 星性压抑, 需后天环境配合 |
| 陷(落陷) | 最弱 | 负面特质易显 | 该星的"软肋"容易暴露, 解读为"课题较重、要更用力", 不等于命运差 |

两点注意:
1. 煞星例外逻辑: 羊陀火铃在庙旺之位, 传统认为破坏性减轻、转为爆发力; 落陷时负面影响才较明显。
2. 落陷的写法: 落实为"这颗星的课题是……, 建议从……入手", 不写"命差""运势差"这类判决语。

## 三、使用提醒
1. 六吉星入命宫或三方四正, 主助力、人缘与贵人运, 解读时指出"贵人在哪类人身上"(魁钺=长辈, 辅弼=平辈, 昌曲=文书才华)。
2. 六煞星入命不直接断凶, 统一口径为"磨练与动力": 羊陀主打磨耐性, 火铃主急躁与突发, 空劫主物质与理想的落差。
3. 红鸾天喜重点用于感情维度; 天刑天姚用于感情与职业风格点缀即可, 篇幅宜少。
4. 辅煞星的具体落宫与组合以排盘 JSON 为准, 本表只提供象征含义。
